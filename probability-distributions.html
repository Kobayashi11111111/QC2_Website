確率分布

確率変数・期待値・分散から、二項分布・ポアソン分布・正規分布の使い分けまでを、数式と図でつなげます。

まずは結論から

確率分布は「どの値が、どのくらい起こりそうか」を表す。

確率変数が取りうる値と、その値をとる確率を対応させたものが確率分布です。QCでは、測定値のばらつきや不適合数などをモデル化し、判断や推定につなげます。

✓

このページのゴール： 二項分布・ポアソン分布・正規分布の使い分けの目安と、期待値・分散が何を表すかを説明できること。

01

確率変数・期待値・分散

RANDOM VARIABLES

確率変数 X は、試行の結果を数値で表すものです。たとえば「10個検査したうち不適合品が何個あったか」は、X=0,1,…,10 の値を取ります。その各値に確率が割り当てられていれば、確率分布として表現できます。

期待値 E(X)

長期的な平均の目安

結果が何度も繰り返されるときの平均的な値。1回ごとの結果そのものを予言する値ではありません。

分散 Var(X)

ばらつきの尺度

期待値のまわりにどの程度散らばるかを表す量。標準偏差はその平方根です。

E(X) = Σ x · P(X=x)離散型の確率変数の期待値
Var(X) = E[(X−μ)²] = E(X²)−μ²μ = E(X)。分散は平均からの二乗偏差の期待値
02

二項分布：一定回数の成功数を数える

BINOMIAL DISTRIBUTION

二項分布は、成功・失敗の2結果からなる独立な試行を n 回行い、成功確率 p が各回で一定のとき、成功回数 X を表します。不適合品数のモデルなどで使われることがあります（各品の状態が独立で、確率が一定とみなせる場合）。

P(X=k) = C(n,k) pᵏ (1−p)ⁿ⁻ᵏk = 0, 1, …, n
E(X)=np　　Var(X)=np(1−p)二項分布の期待値と分散
二項分布の形を変えてみる

試行回数 n と成功確率 p を変更して、成功回数の確率がどう変わるかを見ます。

操作できる例
期待値 np5.00
分散 np(1−p)2.50
標準偏差1.58
棒の高さは各 k における確率 P(X=k) です。p=0.5 では中央付近が高くなり、p を小さくすると小さい成功回数側に確率が寄ります。
03

ポアソン分布：一定範囲での発生回数

POISSON DISTRIBUTION

ポアソン分布は、一定の時間・面積・長さなどの範囲で、まれな事象が何回起きるかをモデル化する際に使われます。平均発生回数を λ とします。近似的には、二項分布で n が大きく p が小さく、np が一定程度のときにポアソン分布が使えることがあります。

P(X=k)= e⁻λ λᵏ / k!k = 0, 1, 2, …　　E(X)=λ、Var(X)=λ
!

モデルを選ぶ条件が大切。 二項分布は「決まった回数の試行における成功数」、ポアソン分布は「一定範囲での発生回数」が典型的です。現実のデータが条件を満たすかは別途確認が必要です。

04

正規分布：連続的な測定値をモデル化する

NORMAL DISTRIBUTION

正規分布は左右対称の釣鐘形の連続分布です。平均 μ は中心、標準偏差 σ は広がりを表します。測定値の誤差や工程データを近似するモデルとして使われますが、すべての品質データが正規分布に従うわけではありません。

Z = (X − μ) / σ標準化：平均から何標準偏差ぶん離れているかを表す
正規分布のイメージ

平均を中心に対称で、平均から遠い値ほど出現確率が低くなります。

概念図
標準正規分布は平均0、標準偏差1です。標準化すれば、異なる尺度の値を同じ基準で比較できます。

QC検定2級では、分布の形だけでなく、確率分布が推定・検定の計算でどのように使われるかも重要です。自由度を持つ t 分布・χ²分布・F 分布は、別ページ「自由度」で扱います。
