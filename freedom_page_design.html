自由度を、
公式の暗記で終わらせない。

「なぜ n−1 なのか」「なぜ回帰分析では n−2 なのか」。自由度を、制約と推定の考え方から理解し、問題に合わせて判断できるようになるための解説です。

THE CORE IDEA
df = n − p
考え方の目安：
データ数 n から、推定したパラメータ数 p を考える。
1制約を見つける
2何を推定したか確認
3モデルごとの式を選ぶ
まずは結論から

自由度は「制約を考えたあとに残る、独立な情報の数」。

自由度（degrees of freedom、df）は、統計量やモデルの中で、制約を満たしながら独立に変化できる情報の数を表す考え方です。まずは「決められる値が何個残るか」という直感から入り、次に何を推定したかを確認すると、公式の違いを整理しやすくなります。

df
まず確認するのは「何の自由度か」。

標本分散、t検定、回帰分析、分散分析では、対象となる統計量・モデルが異なります。「データ数 − 推定パラメータ数」は有力な見方ですが、すべての場面に機械的に当てはめられる万能公式ではありません。

このページの学習ゴール： 自由度の直感をつかみ、代表的な場面で式を選び、なぜその自由度になるのかを説明できること。

値が3個あっても、「合計を12にする」という制約があるため、3つを完全に独立には決められません。この単純な例では自由に選べる値は2つです。

標本平均からの偏差にも、同じ制約がある

データが 2、4、6 なら標本平均は 4、偏差は −2、0、2 です。偏差の合計は必ず 0 になります。3つの偏差を好き勝手に決めることはできず、最初の2つを決めると、最後の1つは合計が0になるように定まります。

(−2) + 0 + 2 = 0

この「合計が0」という制約が、標本分散で n−1 が現れる直感的な理由です。ただし、標本分散を n−1 で割る統計的な理由（母分散を不偏に推定する性質）は、次の節で確認します。

02

なぜ標本分散では n−1 なのか

THE REASON BEHIND n − 1

標本分散では、母平均が分からないときに標本平均 x̄ を使って、各データの偏差（データ − 標本平均）を求めます。ここで、偏差には重要な性質があります。

DEVIATIONS FROM THE SAMPLE MEAN
∑ (xᵢ − x̄) = 0
標本平均からの偏差を全部足すと、必ず0になる。
1

n個のデータがある

標本には x₁, x₂, …, xₙ の n 個の観測値がある。

2

標本平均を計算する

x̄ = (x₁ + x₂ + … + xₙ) / n とし、その平均を基準に偏差を作る。

3

偏差には1つの制約がある

偏差の合計が0と決まるため、n−1個の偏差を決めれば、残り1個は合計が0になるように決まる。

SAMPLE VARIANCE
s² = Σ(xᵢ − x̄)² / (n − 1)
標本平均を同じデータから推定するため、分散の推定では n−1 が現れる。
もう一段深く：なぜ n−1 で割ると、母分散を偏りなく推定できるのか

共通の平均 μ、共通の分散 σ² をもつ独立な標本 X₁,…,Xₙ を考えます。標本平均 X̄ は真の平均 μ の代わりにデータから推定した値です。そのため、標本平均の周りの平方和は、真の平均の周りの平方和より平均的に小さくなります。

E[Σ(Xᵢ − X̄)²] = (n − 1)σ²

この結果は、次の分解から導けます。

Σ(Xᵢ − X̄)² = Σ(Xᵢ − μ)² − n(X̄ − μ)²
  1. 真の平均 μ からの平方和の期待値は nσ²。
  2. 標本平均 X̄ の分散は σ²/n なので、引かれる項の期待値は n × (σ²/n) = σ²。
  3. したがって、平方和の期待値は nσ² − σ² = (n−1)σ²。
s² = Σ(Xᵢ − X̄)² / (n − 1)　⇒　E[s²] = σ²

これが、標本分散 s² が母分散 σ² の不偏推定量になる理由です。ここでの不偏性の説明には、独立で同じ分散をもつ標本を想定しています。

!
正規分布の仮定が必要な話も区別しよう

偏差の合計が0であること自体は、正規分布を仮定しなくても成り立ちます。一方、(n−1)s²/σ² が自由度 n−1 のカイ二乗分布に従うという結果には、通常、独立な正規標本という条件が必要です。

?
では、なぜ n で割る式も見かけるの？

母集団全体を観測できている場合の母分散は、母平均 μ からの偏差平方和を母集団の個数 N で割ります。一方、母平均も母分散も未知で、標本から母分散を不偏推定する標本分散では、標本平均 x̄ を使い n−1 で割ります。「n か n−1 か」だけを暗記せず、何を計算・推定しているかを確認しましょう。

03

では、回帰分析で n−2 になるのはなぜ？

WHY TWO DEGREES ARE USED
先
先に結論

切片を含む単回帰分析では、データから「直線の高さ」と「直線の傾き」の2つを決めます。そのため、残差に残る自由度は n − 2 になります。ここでは、式を暗記する前に、何が起きているかを図で見てみましょう。

1. 回帰直線は、データに合わせて「高さ」と「傾き」を決める

回帰分析では、データの傾向を1本の直線で表します。直線は ŷ = a + bx と書けます。a（切片）を変えると直線全体が上下に動き、b（傾き）を変えると直線の傾きが変わります。

a
切片：高さを調整直線を上下に動かす
↕
b
傾き：角度を調整直線を急に／緩やかにする
／

各データの観測値 y と、直線が予測する値 ŷ の差を残差といいます。最小二乗法は、残差を二乗して足した値が最小になるように、切片と傾きを選びます。

RESIDUAL
eᵢ = yᵢ − ŷᵢ
点が直線より上なら残差は正、下なら負。図の縦線が、その差を表しています。
具体例：4個のデータに直線を当てはめる観測値と、回帰直線が予測する値の差を見る
n = 4
観測値回帰直線（予測値）残差（縦の差）

図の4点は説明用の例です。直線は ŷ = 2 + x。観測値は 4, 3, 4, 7 で、予測値との差（残差）は +1, −1, −1, +1 になります。

2. 残差は4個ある。でも、好きな値を4個とも自由には選べない

この例では、残差は4個あります。しかし、最小二乗法で切片と傾きを調整した結果、残差には次の2つの条件が成り立ちます。

条件 1
Σ eᵢ = 0
残差を全部足すと0

直線より上のずれ（正）と、下のずれ（負）が、合計では打ち消し合います。

+1 − 1 − 1 + 1 = 0
条件 2
Σ xᵢeᵢ = 0
x を掛けて足しても0

残差に、x が大きくなるほど一方向にずれるような直線的な傾向が残っていません。傾き b を調整した結果です。

1×1 + 2×(−1) + 3×(−1) + 4×1 = 0
!
「残差の合計が0」だけでは、まだ1つしか条件がない

回帰では、残差の合計が0になることに加えて、x と残差の積和も0になります。この2つの独立した条件が、自由に動かせる残差の数を2つ分減らします（x に変化があり、切片と傾きが推定できる通常の単回帰の場合）。

3. 4個の残差なら、自由に決められるのは2個分

上の例で、最初の2つの残差を e₁ = +1、e₂ = −1 と決めると、残りの2つは条件を満たすように決まります。

先に決めるe₁ = +1e₂ = −1ここは例として選んだ値
→
条件から決まるe₃ = −1e₄ = +1合計と積和が0になる値

つまり、4個の残差があっても4個すべてを独立には決められません。この例では、2つを決めると残り2つは条件に縛られます。自由に動かせる残差の数は 4 − 2 = 2 です。

RESIDUAL DEGREES OF FREEDOM
n − 2
n個の観測値から、切片と傾きの2係数を推定するため、残差の自由度は n−2。
もう少し数学的に確認する（最小二乗法の条件）

最小二乗法は、残差平方和 S = Σ(yᵢ − a − bxᵢ)² = Σeᵢ² を最小にする a と b を選びます。

a（切片）について最小になる条件を考えると、Σeᵢ = 0。b（傾き）について最小になる条件を考えると、Σxᵢeᵢ = 0 が得られます。

この2条件が独立である（x に十分な変動があり、2係数を区別して推定できる）ため、残差ベクトルが動ける空間の次元は n − 2 です。これは通常の切片あり単回帰に対する説明であり、すべての回帰モデルに無条件で当てはまるわけではありません。

↔
自由度の分解ともつながる

切片を含む単回帰では、全体の自由度 n−1 が、回帰の自由度 1 と残差の自由度 n−2 に分かれます。
n − 1 = 1 + (n − 2)

注意：n−2 は「切片ありの単回帰分析」での残差自由度です。説明変数が複数ある重回帰では、推定する係数の数に応じて変わります。また、切片を含まないモデルでは、同じ式をそのまま使えません。

COMMON PATTERNS

自由度は「いつでも n−1」ではありません。何を推定・比較しているか、どのモデルを使っているかを確認してから選びます。

場面自由度条件・見分けるポイント
1標本 t 検定n − 1母分散が未知で、標本標準偏差を使う。厳密な t 分布による推論では、通常、母集団の正規性を仮定する。
正規母集団の母分散の検定n − 1標本分散から作るカイ二乗統計量を用いる。
2つの母分散の比（F検定）分子：n₁ − 1
分母：n₂ − 1		独立な正規標本を想定。F比の分子と分母の順に自由度を指定する。
対応のある t 検定npair − 1ペアごとの差を1標本として扱う。npair はペア数。厳密な t 分布による推論では、差の分布の正規性が前提となる。

05

自由度は、何に使われるのか

FROM DEGREES OF FREEDOM TO DISTRIBUTIONS

自由度は、表の空欄を埋めるためだけの数ではありません。検定統計量が従う分布を決めたり、分散分析で平方和を「自由度あたり」に換算したりするときに使います。

t 分布

母分散が未知の平均の推定・検定などで使う。標本数 n の1標本 t 検定なら自由度は n−1。

カイ二乗分布

正規母集団の分散に関する検定などで使う。標本分散に基づく統計量では自由度 n−1 が現れる。

F 分布

分散の比や分散分析で使う。分子側と分母側に、それぞれ別の自由度を指定する。

操作して比較：自由度で t 分布の形はどう変わる？

青線が選択した t 分布、破線が標準正規分布です。

t 分布（選択した自由度）標準正規分布（比較用）
読み取りのポイント自由度が小さい t 分布は、標準正規分布より裾が厚くなります。自由度が大きくなるほど、標準正規分布に近づきます。
ANALYSIS OF VARIANCE
平均平方 = 平方和 ÷ 自由度
自由度は、ばらつきの平方和を分散比の計算に使える形へ換算する役割もある。
↗
試験で大事なポイント

同じ「標本数 n」でも、どの分布・どの平方和・どの検定を使うかで自由度は変わります。F 分布では、自由度の分子・分母の順を入れ替えないようにします。

例でつなぐ：一元配置分散分析

PUT THE PIECES TOGETHER

3つの条件（k = 3）で、合計12個（N = 12）の観測値を得たとします。群の平均を使って群間の変動を、各データと所属する群の平均との差から群内の変動を考えます。

変動の種類自由度の式この例意味
群間k − 13 − 1 = 2群の平均どうしの違い
群内N − k12 − 3 = 9各群の中に残るばらつき
合計N − 112 − 1 = 11全データの総変動
合計の自由度を分けて見る合計 11
2
9
群間：k − 1 = 2群内：N − k = 9

この例では、全体の自由度11が「群の平均の違い」に対応する2と、「各群内に残るばらつき」に対応する9に分かれます。

CHECK THE DECOMPOSITION
11 = 2 + 9
合計の自由度 = 群間の自由度 + 群内の自由度

ここで大切なのは、群間は群数 k、群内は全データ数 N と群数 k の両方を使うことです。分散分析表で自由度を埋めるときに、群数と観測数を混同しないようにしましょう。

07

よくある間違い

COMMON PITFALLS
MISTAKE 01

自由度は常に n−1

n−1 は標本分散や標準的な1標本 t 検定で現れるが、回帰や分散分析では別の式になる。

BETTER THINKING

まず「何の自由度か」を確認

検定統計量なのか、回帰の残差平方和なのか、分散分析の群間・群内なのかを特定する。

MISTAKE 02

標本分散は、なぜ n で割らない？

標本平均を使って母分散を不偏推定する標本分散では n−1 で割る。単にデータを記述する計算とは目的が違う。

BETTER THINKING

式だけでなく、推定の目的を見る

母分散を標本から推定するのか、すでにあるデータ全体の散らばりを記述するのかを区別する。

MISTAKE 03

回帰なら必ず n−2

n−2 は、切片を含む単回帰の残差自由度。切片なしや重回帰では、モデルの係数数と条件を確認する。

BETTER THINKING

モデルの形を読み取る

切片・傾き・その他の係数をいくつ推定したか、説明変数に十分な変動があるかを確認する。

MISTAKE 04

F検定の自由度の順を逆にする

F統計量は分子の平均平方・分散を分母で割るため、分子と分母で使う自由度が異なる。

BETTER THINKING

統計量の式から順番を決める

まず F = 分子 ÷ 分母の式を書き、各側に対応する自由度を指定する。
