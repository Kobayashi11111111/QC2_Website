QC Study — QC検定2級 学習サイト試作

開き方：index.html をブラウザで開き、各ページへ移動してください。

ページ構成：
- index.html: サイトの入口・QC検定2級トップページ
- math-statistics.html: 数学・統計の学習ガイド
- statistics-basics.html: 平均・分散・標準偏差（データの基礎）
- probability-distributions.html: 二項分布・ポアソン分布・正規分布
- estimation-testing.html: 標準誤差・信頼区間・仮説検定・p値
- regression-analysis.html: 相関・回帰分析・残差・決定係数
- freedom_page_design.html: 自由度の直感・n−1・n−2・検定や分散分析での使用

新しい学習ページには、外部JavaScriptライブラリを使わないSVGグラフとミニテストを含みます。
